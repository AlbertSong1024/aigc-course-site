# AIGC应用与实践 · 课程教程站

广州城建职业学院《AIGC应用与实践》（2026-2027 学年第 1 学期，人工智能专业大三）的课程教程站。
把**全部 32 次课 / 64 课时**重排成一份类似菜鸟教程的**可照着做的教程**：每课结构固定，先讲原理、再给命令与代码、然后是能当场跑起来的演示，最后是自测与作业。

> **状态：32 / 32 课全部上线**（2026-09-26 收官），全站校验 **通过 659 · 警告 0 · 失败 0**。

---

## 特性

- **纯静态、零 CDN、断网可用**：HTML + CSS + 原生 JS，无任何外部依赖，`file://` 双击任意页面即可打开；
- **单一数据源**：左侧目录、首页课程地图、顶部课次下拉、上一课/下一课、全站搜索，全部由 `assets/js/course-map.js` 驱动；
- **统一设计系统**：全站只用两个主色（蓝 `#2563EB` + 橙 `#F59E0B`），样式集中在 `assets/css/site.css`，课时页不写行内样式；
- **每课标配可运行演示**：纯前端模拟，不联网、不装环境也能看懂机制；示意数据一律标注「教学示意，非实测数值」；
- **每课配一个已核验的 B 站延伸视频**：`data-src` 滚动懒加载（滚到那一屏才载播放器），视频 ID 均经 B 站官方接口核对；
- **内置课程 AI 助教**：右下角蓝色浮窗，离线可导览、填自己的 Key 后可基于课时正文解答；
- **内置学情采集**：右下角橙色「学情」浮窗，本地记录学习轨迹并可导出，老师端可离线汇总成班级学情；
- **可校验**：`tools/check_site.js` 做结构、锚点、索引、语法、冒烟、版式六类检查。

## 快速开始

```
直接双击 index.html
```

不需要起服务器、不需要安装任何东西。左侧目录点课次即可进入。

如果想让地址栏有真实路径（便于截图、局域网分享），起一个本地服务器：

```bash
# 在 tutorial-site/ 目录下执行
python tools/serve.py          # 默认 8806，只监听本机
python tools/serve.py 9000     # 或指定端口
# 然后访问 http://127.0.0.1:8806/index.html
```

> ⚠️ **请用 `tools/serve.py`，不要用 `python -m http.server`。**
> 后者会让浏览器缓存 `course-map.js` / `site.js`，改了数据源后刷新仍可能拿到旧版，
> 典型症状是「新课明明做完了，侧栏里那几课还是点不动」。`tools/serve.py` 对所有响应加了
> `Cache-Control: no-store`，刷新即生效。注意只监听 `127.0.0.1`，不要绑 `0.0.0.0`。

**怎么确认看到的是最新版？** 看页面**页脚**：

```
AIGC应用与实践 · 广州城建职业学院 · 2026-2027 学年第 1 学期 | 课程教程站 v1.0 | 已上线 32 / 32 课
```

数字是动态算出来的，不是写死的。若显示偏小，说明加载的是缓存，按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> 强制刷新。

## 课程 AI 助教

每个页面右下角有**蓝色「AI」浮窗**，两种模式：

| 模式 | 条件 | 能做什么 |
|---|---|---|
| **离线导览** | 默认，无需任何 Key | 按关键词匹配站内章节，给出「去第 N 课某一节」的直达链接，**断网也能用** |
| **联网解答** | 在 ⚙ 里填自己的 API Key | 基于**当前课时正文**回答；卡在实操时可贴报错让它定位步骤、给排查思路 |

支持 DeepSeek / 通义千问 / 自定义 OpenAI 兼容接口。**Key 只存学生本机浏览器**，对话只发往所选服务商，不经任何中间服务器。设置面板可一键清除 Key。

> 个别服务商不允许浏览器直连（CORS）。若联网解答报错，用 `tools/serve.py` 打开本站，或先用离线导览。

## 学情采集

学生每打开一个页面，右下角**橙色「学情」浮窗**会在本机记录：到课、停留时长、演示次数、自测自评、问 AI 助教的记录、是否展开作业、是否看了视频。

- **对学生**：面板里可看自己的学习进度，**一键导出 JSON** 当作业交；
- **对老师**：打开 `tools/teacher-dashboard.html`，把全班导出的 JSON 拖进去，即可在**你自己电脑上**汇总出班级学情——人均到课/停留/自测、**各课学习人数热度**、**高频提问 Top12**，并可导出 CSV；
- **隐私**：默认匿名（随机 ID），姓名学号由学生自愿填写、可空；**数据不上传任何服务器，断网也能记**；
- **可选上报**：若老师自建了上报端点，在浏览器控制台执行
  `localStorage.setItem('lt_endpoint_v1','https://你的端点')`，此后离开页面会自动匿名上报汇总指标。未配置端点则完全不联网。

## 怎么新增 / 修改一课

```bash
# 1. 生成页面骨架
node tools/new-lesson.js 8

# 2. 写内容（严格按 CONVERSION-SPEC.md 第三节的六小节结构）
#    编辑 lessons/lesson-08-*.html

# 3. 登记数据源（两步都不能漏）
#    assets/js/course-map.js    → 该课 status 改为 "ready"
#    assets/js/search-index.js  → 追加该课全部小节索引

# 4. 过校验（必须「失败 0」才算完成）
node tools/check_site.js 8
```

**批量转化的分工铁律**：多人并行时，只让各自写 `lessons/*.html`；`course-map.js` 与 `search-index.js` **由一个人统一收口**，避免并发改同一文件互相覆盖。

校验脚本依赖 `jsdom`：

```bash
cd "C:/Users/Albert/.workbuddy/binaries/node/workspace" && npm i jsdom
NODE_PATH="C:/Users/Albert/.workbuddy/binaries/node/workspace/node_modules" node tools/check_site.js
```
