本课导读模块二 · 接上你的资料

上一课你在 ima 里亲手建了一个知识库，也在 ima 里问过问题。 那一课的方向是「你走进 ima 的房间去翻资料」。 这一课换方向——让 WorkBuddy 这只手伸进你的库里，替你翻、替你答、替你把产物存回去。

先确认三件你大概率会遇到的事：

  • 知识库建好了，WorkBuddy 却说「没找到你的资料」——两边根本没打通， 它手上没有进门的凭证。
  • 打通之后，它答得很顺，但你不知道哪句来自你的资料、哪句是它自己补的—— 没有引用，等于回到了凭记忆回答。
  • 把一串密钥贴进对话让它配置——省事了，但那串字符串从此躺在对话记录里。

这一课按四步走：① 把凭证领出来、放对地方 → ② 绑定知识库、看清授权了哪三项 → ③ 在任务里带引用地问答 → ④ 划清权限边界，资料里没有时让它明确拒答。 RAG 的原理不再重复讲，需要回顾时翻 第 15 次课。

提前说清楚 本课最容易理解错的一点：「连上」和「答得对」是两件事。 连上只解决了「它能碰到你的资料」，不解决「它会照着你的资料说」。 所以本课一半的篇幅放在引用和拒答上——那是让知识库真正有用的部分。

本页涉及 WorkBuddy 与 ima 的产品事实，核对日期 2026-09-25， 依据为 www.workbuddy.cn 官方文档《WorkBuddy × ima 功能指引》 《如何用 WorkBuddy 把 ima 知识库越用越厚》《连接器》三篇， 以及 ima 官方凭证页 ima.qq.com/agent-interface。 客户端文档与开放平台文档能力不同，本页不混用； 查不到官方口径的地方一律写「不确定」，并以你实际使用的版本为准。

学习目标

学完这一课，你应该能——

  1. 说清让 WorkBuddy 触碰你 ima 资料的两条路（扫码授权 / API Key 凭证）差在哪， 并说出三条 API Key 的安全红线；
  2. 在 WorkBuddy 里独立完成 ima 知识库的绑定， 并逐条说出它拿到的三项权限分别是什么；
  3. 发起一次带引用的问答，拿到答案后按「文件名 / 位置 / 原句」三要素核完溯源；
  4. 写出一条能让它拒答的指令——限定依据范围、写死红线、说清缺信息怎么办；
  5. 判断一件事该不该交给它做（权限边界三条 + 积分口径）， 并说清什么时候该解绑。

一、API Key 配置：把钥匙领出来，放对地方凭证

先讲个比方。扫码授权像去前台登记领一张临时工牌： 登记一次，工牌由系统管着，你随时能注销，注销完它就进不了门。 API Key 像配了一把你家的钥匙给别人：谁拿到这串字符串，谁就能开门， 而且它不会自己失效。

所以要分清你现在走的是哪条路。

维度扫码授权（官方内置连接器）API Key（ima 开放接口凭证）
官方依据 www.workbuddy.cn《WorkBuddy × ima 功能指引》 ima.qq.com/agent-interface（ima 官方凭证页）
拿到的是什么 一次授权关系，凭据由 WorkBuddy 维护，你不用抄 一串密钥字符串（页面上还可能出现 Client ID，以页面实际显示为准）
存在哪 不用你管 要你自己保存，并填给调用方——这一步是本课的重点
撤销方式 个人版连接器可解除绑定；企业版由企业统一管理，端内不支持解绑 回凭证页重新获取，让旧的字符串失效
是否支持「重新生成」按钮，本页核对时未能确认，不确定，以页面显示为准
典型用途 在 WorkBuddy 桌面端里日常调用知识库 把 ima 能力接给脚本、命令行、其他智能体（技术向场景）

按 WorkBuddy 官方《连接器》一节的口径，授权凭据包括 OAuth Access/Refresh Token，或您手动填写的 API 密钥—— 也就是说「填密钥」这回事本身是被产品支持的能力，只是ima 这一路的具体填写入口， 官方客户端文档里没有写明。本页因此只讲通用的安全做法，不编造入口名。

风险等级与扩散范围是定性判断的教学示意，不是产品给出的安全评级， 用来建立「同一串字符串，位置不同、后果差别很大」的直觉。

三条红线，一条都不能破

  1. 不硬编码进代码写死在脚本里，代码一分享、一提交，密钥跟着走。 要用环境变量或本地配置文件读取。
  2. 不整段贴进对话对话记录可能被同步、导出、截图、转给他人。 真要配置，让它去读你本地的那个文件，而不是你把内容复述给它。
  3. 不交给第三方工具来源不明的「一键配置脚本」「帮你接入的小工具」， 接过你的密钥就等于接过你的账号。
官方原话，记住这句 WorkBuddy 官方《连接器》一节的安全提示原文： 「API 密钥与 Token 是访问您第三方账号的钥匙，请妥善保管，避免在公共设备或共享环境填写； 不再使用的连接器建议及时撤销授权。」
另一句是免责声明：「自定义连接器的访问范围由您的配置决定，WorkBuddy 不预设范围， 请审慎评估后再启用。」
实操 ①·领出凭证，放到只有你能读的地方 约 8 分钟

做完你手上会有：本地 ~/.config/ima/ 下两个凭证文件， ＋ WorkBuddy 读出你的 ima 知识库列表的一段回答（全程密钥没有出现在对话里）。

第 1 步 · 到 ima 官方凭证页领钥匙（2 分钟）

  1. 浏览器打开 ima.qq.com/agent-interface 并登录 用你建库时那个 ima 账号。
  2. 点页面上的「获取 API Key」页面会给出一串密钥； 如果同时显示了 Client ID，两个都要留着——以页面实际显示为准。
  3. 先复制下来，暂时别发给任何人、也别发进任何对话 这一步最容易做错：看到「配置」两个字就顺手贴给 AI。先忍住。

第 2 步 · 用下面这组命令把它写进本地文件（2 分钟）

打开 PowerShell，把下面这段整段复制进去执行。 先把 你的ClientID 和 你的APIKey 换成第 1 步拿到的真实值：

New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.config\ima" | Out-Null
Set-Content -Path "$env:USERPROFILE\.config\ima\client_id" -Value "你的ClientID" -Encoding utf8 -NoNewline
Set-Content -Path "$env:USERPROFILE\.config\ima\api_key"   -Value "你的APIKey"   -Encoding utf8 -NoNewline
Get-ChildItem "$env:USERPROFILE\.config\ima"

第 3 步 · 让 WorkBuddy 自己去读，不要把内容贴给它（2 分钟）

在 WorkBuddy 里新建一个对话，把下面这段指令整段发出去—— 注意里面一个密钥字符都没有：

我已经把 ima 的开放接口凭证写在这两个本地文件里：
%USERPROFILE%\.config\ima\client_id
%USERPROFILE%\.config\ima\api_key

请读取这两个文件完成 ima 连接配置，然后做两件事：
1. 列出我 ima 账号下的知识库名称；
2. 告诉我你现在能对这个知识库做什么、不能做什么。

要求：不要在回复里回显这两个文件的完整内容，只回显前 4 个字符用于我确认读对了文件。
读不到就直说"读不到"，不要猜、不要编造知识库名称。

第 4 步 · 做到这三条，就算做完了

  1. 它列出了你真实的知识库名称至少能说出你在 第 15 次课建的那个库。
    它说读不到：先确认第 2 步命令没报错、文件真的存在 （用第 2 步最后那条 Get-ChildItem 再看一眼）， 再把「读不到就直说」这句挪到指令最前面重发一次。
  2. 回复里没有出现完整密钥最多只有你让它回显的前 4 个字符。
    它整段吐出来了：⚠️ 说明「不要回显」那句没生效。 这段对话别再转发给任何人，并回到 ima.qq.com/agent-interface 重新获取一次，让这串字符串作废。
  3. 两个凭证文件在 .config\ima\ 下，不在你的工作目录里 工作目录里的文件随时可能被 AI 读走、被打包、被同步。
    放错位置了：把文件移走，再执行第 2 步的命令重新生成一次。

要交的成果：它列出知识库那段回答的截图 ＋ 一句「我的凭证放在哪、为什么放那儿」。 截图里不要出现完整密钥——出现的话打码再交。

如果你手上的版本没有「让 AI 读本地文件完成配置」这条路， 那就不要勉强：直接用第二节的扫码授权即可， 日常在 WorkBuddy 里调知识库走那条路就够了。本节的凭证只在你确实要把 ima 接给脚本或其他智能体时才需要。

二、绑定知识库：让它看见你有几个库本课核心

上一节解决的是「凭证」，这一节解决的是「关系」。 凭证是钥匙，绑定是拿这把钥匙去开哪一扇门、开到什么程度。

按 WorkBuddy 官方《WorkBuddy × ima 功能指引》， ima 知识库连接器按账号所在环境分两种：

使用环境提供的连接器授权方式能不能解绑
iOA 企业账号 ima 知识库企业版 ＋ 个人版 双连接器 企业版走企业统一身份，无需单独扫码 企业版不支持端内解绑，由企业统一管理
其他企业旗舰版 ima 知识库个人版 连接器 个人微信扫码授权 支持随时解绑

官方原话：「两个连接器的授权状态相互独立、互不影响； 在连接器面板点击连接即可进入对应授权页，授权完成后连接状态即时刷新。」

授权页上那三项权限，逐条看清楚

扫码之后还会弹一次确认页。官方写明的三项是原文照抄的，逐条读一遍再点同意：

权限项（官方原文）翻译成人话你要想一下的是
在 WorkBuddy 中查看我的知识库列表 它能看到你建了哪些库、叫什么名字 库名里别写敏感信息
查看或搜索知识库资料 它能读库里的文件内容 不该给 AI 看的东西别放进去
将知识库文件添加到任务或者将文件保存到 ima 知识库 它能把文件拉进任务，也能往你的库里写东西 这是写权限——产物存回时用得到，也意味着它可能往里放东西
官方还有一句 TIP 「WorkBuddy 连接资料库的 ima 知识库后将获得登录用户的 ima 知识库的权限。」 换句话说：它能看的范围 = 你这个账号本来就有的范围，不会因为你授权给它而变大。 但反过来也成立——你账号能看到的共享库内容，它一样能看到。

实操 ②·绑定 ima 知识库，逐条核对三项权限 约 10 分钟

做完你手上会有：一个已连接的 ima 知识库， ＋ 一份「它现在能做什么、不能做什么」的核对结论。

第 1 步 · 走完绑定（3 分钟）

  1. 在 WorkBuddy 左侧边栏点「资料库」，选「ima 知识库」 官方路径就是这一条，不是「连接器」那一个入口。
  2. 点「立即前往授权」用微信扫码登录 ima。扫的是你建库那个账号， 扫错了账号，后面看到的是另一个人的库。
  3. 在确认页上，把三项权限逐条读完再点同意 三条分别是「查看我的知识库列表」「查看或搜索知识库资料」 「将知识库文件添加到任务或者将文件保存到 ima 知识库」。
  4. 回到 WorkBuddy，确认知识库已经出现在列表里 没出现就刷新一次连接状态（官方说授权完成后状态即时刷新）。

第 2 步 · 让它报一遍自己有什么（3 分钟）

新建一个对话，把下面这段指令整段发出去：

你现在已经连上了我的 ima 知识库。请做三件事：

1. 列出你能看到的全部知识库名称和类型（个人 / 共享 / 订阅）；
2. 逐条说明你现在对我这些知识库能做什么、不能做什么；
3. 说明如果没有我的明确指令，你会不会主动去读或改这些库里的内容。

要求：只说你实际具备的能力，不要推测、不要把"理论上可以"写成"可以"。
不确定的地方直接写"不确定"。

第 3 步 · 再让它从库里取出一份文件（2 分钟）

  1. 在输入框上方的「添加文件」图标处打开 ima 知识库 勾选整个库（不是单个文件）——这一节要验证的是「整个库能不能被引用」。
  2. 把下面这段指令发出去整段复制，一个字别改。
请从我刚才添加的 ima 知识库里，列出里面实际有哪些资料，
每条给出：资料名称 + 一句话说明它讲了什么。
只允许列出库里真实存在的内容；库里没有的不要补，读不到就写"读不到"。

第 4 步 · 做到这四条，就算做完了

  1. 列表里出现了你在上一课建的那个主题库 名字应该和你建库时一致。
    列表是空的：先确认扫码的是同一个账号；还不行就点「解除绑定」重新绑一次 （个人版连接器支持解绑）。
  2. 它说出的能力范围，和三项权限对得上 看列表 / 搜索读内容 / 添加和保存文件——三条都在，而且没有多出别的。
    它自称还能做别的：让它说清是哪一项权限允许的；说不清就按「不确定」处理，别信。
  3. 它明确说了「没有你的指令不会主动去读或改」 这对应官方的权限边界「不主动定时抓取」。
    它含糊其辞：补一句「请只回答是或否，并说明理由」，再问一次。
  4. 第 3 步拿到的资料清单和库里的实际内容对得上 你传了 3 份，它就该列出 3 份左右，不该多出你没传过的东西。
    多出了没见过的资料名：⚠️ 两种可能——它读了别的库，或者它在编。 让它逐条标出「这条出自哪个库」，标不出来的就是编的。

要交的成果：绑定成功的界面截图 ＋ 第 2 步那份「能做什么 / 不能做什么」的回答。 这个库留着别动，实操③ 要在里面问答。

三、带引用问答：让它照着你的资料说方法

连上了、也引用了，接下来才是真正容易翻车的地方。 它读了你的库，不代表它会照着你的库说。 RAG 那一步（切片 → 向量化 → 检索 → 增强生成）它自己就跑完了， 你唯一能抓住的是它在答案里留下的引用。回顾原理翻 第 15 次课。

可运行演示 ③ 有引用 ≠ 能核对：两种答案，你该收哪一种
—标出的引用条数
—你能不能核对
两段答案是离线预置的示意文本，用来对比答案结构， 真实效果请在你自己的知识库上验证。

一条合格的引用，要有三样东西

要素长什么样缺了会怎样
文件名《课程笔记-切片.md》你不知道去哪儿找
位置第 2 节「切片时的两个坑」一份长文件里大海捞针
原句把资料里那句话原样摘出来你分不清是引用还是它自己的总结

三样齐了还只算「标了引用」。上一课讲过的三查在这里照样走一遍： 查引用（有没有标）→ 查原文（点回去核，资料里是不是真这么写） → 查边界（资料里没有的，它是不说话还是照编）。

积分口径，顺手记一下 按官方《连接器》一节的说明：连接器自身的读写不消耗积分； WorkBuddy 对外部数据进行理解、汇总时会消耗积分。 翻库、列清单这类动作本身不贵，让它读完再总结、再成文才花钱。 所以「每次都让它把整个库读一遍」是既慢又费的做法—— 先锁定库或文件，再提问。
实操 ③·问两组问题，把引用逐条核回去 约 12 分钟

做完你手上会有：两份带引用的回答， ＋ 一张「引用核对表」（每条结论 → 出处 → 核没核过 → 核的结果）。

第 1 步 · 问第一组：答案确实在库里（3 分钟）

  1. 新建一个对话必须新建， 别接着实操② 的对话问——它的上下文里已经有库的内容了，这次实验就不准了。
  2. 用输入框上方的「添加文件」打开 ima 知识库，勾选你那个主题库 勾选整个库，不要勾单份文件。
  3. 把下面这段指令整段发出去三组约束一句都不能少。
只依据我添加的 ima 知识库里的内容回答，不允许使用库外的任何知识：
这门课给文件命名的规则是什么？切片时要避开的两个坑叫什么名字？

输出要求：
1. 每一条结论后面必须跟一条引用，格式为
   【引用】文件名 · 位置 · 资料里的原句（原样摘抄，不要改写）；
2. 库里没有的信息不要补，直接写"库里没有这项信息"；
3. 答完附一张引用核对表，三列：结论 / 出处 / 我该怎么核。

如果检索不到相关内容，直接说"没有检索到"，不要用自己的知识回答。

第 2 步 · 问第二组：跨两份资料才能答（3 分钟）

这一组的目的，是看它能不能把两份资料里的内容拼起来—— 这是知识库问答比单文件问答强的地方：

只依据我添加的 ima 知识库回答，不允许使用库外的任何知识：
把知识库里的课程笔记和我交过的那份作业对照一下——
笔记里提到的做法，有哪些在我那份作业里其实还没做到？

要求：
1. 必须同时引用课程笔记和作业这两份资料，逐条对照；
2. 每条结论后面给出【引用】文件名 · 位置 · 原句；
3. 只讲两份资料里都能找到依据的部分，只在一边出现的不要写结论。

第 3 步 · 让它把核对表补完整（2 分钟）

在你认为最关键的那一条上追一句，把下面这段紧接着发过去：

挑你这次回答里最关键的一条结论，把它的引用补全成三样：
1. 出自哪个文件的哪一小节；
2. 资料里的原句（原样摘抄，不要改写、不要概括）；
3. 你判断这条结论时，还参考了库里的哪些其他片段。

如果这条结论其实不是来自库里，明说"这条不是来自库里"。

第 4 步 · 做到这四条，就算做完了

  1. Q1 的每条结论后面都有【引用】，而且三样齐全 文件名、位置、原句——缺一样就不算合格。
    只给了文件名：把「文件名 · 位置 · 原句（原样摘抄，不要改写）」 这句单独再发一次，让它按格式重出。
  2. 你点开核过至少一条 拿它给的「位置」回到 ima 里翻到那一处，看资料里是不是真这么写。
    点不回去 / 原文对不上：这条答案按没有引用处理， 不要拿它当结论用。
  3. Q2 同时提到了两份资料 笔记里的做法 ＋ 作业里的实际情况，两边都点到，而且各自有引用。
    它只讲了一边：补一句「必须同时引用课程笔记和作业两份资料，逐条对照」。
  4. 追问后，它能说清那条结论出自哪里 这是最难的一条，也是最有价值的一条。
    它说「这条不是来自库里」：恭喜，实验成功了—— 这正是你要的结果：它自己承认了这条没有依据。把这轮对话留着， 实操④ 要接着用。

要交的成果：Q1、Q2 两份回答截图 ＋ 引用核对表 ＋ 一句「我核了哪一条、结果对不对」。

四、权限边界与拒答策略红线

前面三节都在让它「多做一点」。这一节反过来——让它在该停的地方停下来。 两件事：它不该碰的东西有哪些，以及资料里没有时它该怎么答。

官方写的三条权限边界

WorkBuddy 官方《连接器》一节给出的边界，原文三条，一条比一条实在：

边界（官方原文）什么意思你怎么验证
每个连接器独立授权 连了 ima 不代表连了邮箱、不代表连了网盘 去「连接器」页面看，只有你授权的才亮着
不主动定时抓取 你不发指令，它不会自己去翻你的库 实操② 第 2 步已经让它亲口确认过一次
不超出您已有权限范围 它看到的 = 你这个账号本来就能看到的 你账号看不到的共享库内容，它也拿不到
反过来想这一条 「不超出你已有权限」意味着：共享知识库里，同库成员能看到的东西，它也能看到。 所以不要把别人的个人信息、没公开的成绩、身份证号之类放进共享库 ——放进去等于同时给了它。这一条不是它的问题，是你放什么进去的问题。

资料里没有时，它该怎么答

这是本课最后一个、也是最实用的一招。上一课说过： 指望「提醒它别瞎编」基本没用，你越说「不知道就说不知道」， 它越可能先编一段再补一句「仅供参考」。 有效的是把三件事同时写进指令：

  1. 限定依据范围「只依据 XX 知识库」——先圈住它能在哪儿找。
  2. 写死红线「不允许使用库外的任何知识」——不许它拿常识补。
  3. 说清缺信息怎么办「库里没有就直接回答『库里没有这项信息』」——给它一个体面的退路， 它才不用靠编来交差。

三句的顺序也有讲究：限定范围放最前面最稳。 放在末尾，它读完全文可能已经先入为主地开始编了。

做完你手上会有：一组「库里根本没有」的问答， ＋ 一份边界检查报告（哪些能做、哪些不做、依据哪条权限）。

第 1 步 · 问一个库里绝对没有的问题（3 分钟）

  1. 新建一个对话又是新建—— 上一节的对话里已经问过库里的内容，接着问它就能猜到「还是那个库」。
  2. 还是勾选同一个 ima 知识库库要在，问题要超出这个库。 这样才测得出「它会不会越界去补」。
  3. 把下面这段指令整段发出去问的是你的资料里绝不可能有的东西。
只依据我添加的 ima 知识库回答，不允许使用库外的任何知识，
不允许用常识、推测、行业通例来补：

这门课期末考试的具体时间是几月几日？试卷一共有几道大题？
实训室工作日的开放时间是几点？

如果库里没有这些信息，请直接回答"库里没有这项信息"，
一条都不要少答，也不要把没查到的写成【待确认】之外的任何具体内容。
答完请说明：这几条你分别检索了哪些片段，检索结果是什么。

第 2 步 · 再让它自查一遍边界（3 分钟）

把下面这段紧接着发在同一个对话里：

针对我现在连上的 ima 知识库，给我一份边界检查报告，四列：

1. 能做：你确认自己可以做的事；
2. 不能做：你做不到、或不被允许做的事；
3. 要我先确认：需要我明确指令你才会做的事；
4. 依据：上面每一条分别对应哪一项已授权的权限。

要求：
- 只写你确实具备的能力，不确定的写"不确定"；
- 特别说明：如果没有我的指令，你会不会主动读取或修改这些库；
- 特别说明：共享知识库里其他成员的资料，你能看到哪些。

第 3 步 · 做到这四条，就算做完了

  1. Q3 明确说了「库里没有」，而不是给了日期和题数 这是本组最关键的一条。
    它照样给了具体时间：⚠️ 说明「不允许使用库外的任何知识」这句没写住。 把这句挪到指令第一句再问一次；还是编，就说明这次问答没真正走知识库—— 回头检查第 1 步的库是不是真的勾选上了。
  2. 它说清了检索了哪些片段 能说出「检索了哪几段、结果是什么」，说明它真的查了，而不是凭空答。
    它说不出检索过程：补一句「请说明你检索时实际读取了哪几个片段」，再问一次。
  3. 边界报告里，「不能做」那一列不是空的 敢于说自己不能做什么，才是判断准确的信号。
    全是「能做」：⚠️ 它在讨好你。补一句「请重点列出你做不到的事」， 让它重出一版。
  4. 「要我先确认」那一列里，出现了写操作 往库里保存文件、把文件加进任务这类动作，应该属于「需要你明确指令才做」。
    它把写操作归进了「能做」：让它补一句「指的是你已授权我做， 但我仍会在执行前等你确认」，然后按它说的再验证一次。

要交的成果：Q3 的回答截图 ＋ 边界检查报告 ＋ 一句「它拒答了吗，你怎么判断的」。

收尾动作：如果你用的是个人版连接器， 可以在「资料库 → ima 知识库」右上角点「解除绑定」随时断开。 企业版连接器由企业统一管理，端内不支持解绑—— 这一点官方写得很清楚，别在实训机上反复试。

一句话收口 连接的价值不是「它能碰到多少资料」，而是「它碰到的每一样，你都知道、都能收回来。」 所以每次授权之前看一眼权限项，每次拿到答案之后点一次引用—— 这两下手动，AI 替不了你。

  • B. 扫码是一次授权关系、凭据由 WorkBuddy 维护且可解绑；API Key 是一串字符串，谁拿到谁能用，且不会自己失效

答案：C。这是官方《连接器》一节原文的三条边界。 A 违反「独立授权」；B 违反「不主动定时抓取」；D 正好说反了—— 官方说得很明确：「不超出您已有权限范围」，它能看到的 = 你账号本来就有的范围。 反过来想这一条更实用：共享库里同库成员能看到的东西，它一样能看到， 所以别把别人的个人信息放进共享库。

本课要点回顾

这一课要带走五件事

  1. 两条凭证路，风险完全不同：扫码授权像临时工牌（可解绑、凭据由系统管）； API Key 像家门钥匙（不硬编码、不贴对话、不交第三方）；
  2. 绑定走「资料库 → ima 知识库」，不是「连接器」—— 微信扫码后逐条核对三项权限：看列表 / 搜索读内容 / 添加与保存文件；
  3. 引用要三样齐全：文件名 · 位置 · 原句， 然后按三查走一遍——查引用、查原文、查边界；
  4. 拒答指令三件事：限定范围 + 写死红线 + 给退路， 限定范围放第一句最稳；
  5. 权限边界三条：独立授权 / 不主动定时抓取 / 不超出你已有权限—— 反过来就是共享库里别放别人的个人信息。

下一步棋：这一课你打通的是「一个连接器」。 它的价值已经能看见了——沉淀 → 调用 → 输出 → 回存这条闭环跑得通， 知识库才会越用越厚。 下一课换个位置：第 17 次课把同样的资料 换成本地结构化知识库，看看云端和本地两套方案各自适合什么。

6.（多选）关于连接器的权限边界与积分，下面哪些说法符合官方口径？
A. 每个连接器独立授权，连了 ima 不代表连了邮箱和网盘
B. 没有你的指令，它不会主动定时抓取你的知识库
C. 它能看到的范围不会超出你这个账号本来就有的权限范围
D. 连接器自身读写不消耗积分，但对外部数据进行理解、汇总时会消耗积分
【答案】ABCD
【解析】A、B、C 是官方《连接器》一节原文的三条权限边界；D 是官方的积分口径。特别提醒 C 反过来想更实用：你账号能看到的共享库内容，它一样能看到，所以不要把别人的个人信息、没公开的成绩放进共享库——放进去等于同时给了它。
