访问统计

把学生导出的「学情档案 JSON」拖进来（可多选），本页在你本机算出 「多少人访问、访问多少次、哪次课人最多、哪次课停留最久」，不上传任何服务器，断网也能用。

口径说明：本站是纯静态站，没有后端。这里统计的只是「交了档案的学生」—— 一份档案 = 一位学生（按随机 ID 去重），不是全网站真实访客数。
要看全站真实访客（含没交档案的人），请看 README「外部统计」一节配置的统计服务，两者口径不同，不要混算。
点击选择，或把多个 学情档案_*.json 拖到这里
学生怎么拿到档案？打开教程站任意页面 → 右下角橙色「学情」按钮 → 填姓名/学号 → 「导出档案（交作业）」，把生成的 JSON 交上来即可。
相关页面：tools/teacher-dashboard.html（班级学情汇总，含自测与提问）。
