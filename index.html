AIGC 应用与实践 · 课程教程站

把《AIGC应用与实践》全部 32 次课的课程内容，重排成一份可以直接照着做的教程： 每课固定结构，先讲原理、再给命令与代码、然后是能当场跑起来的演示，最后是自测与作业。 全部页面纯静态、无外部依赖、断网可用，双击任意页面即可打开。

怎么用这个站

给同学 每课的「可运行演示」都是纯前端模拟，不联网、不装环境也能看懂机制； 真正的命令请在你自己电脑上照抄执行。每课最后的「随堂小测」不计分，是给你课后自检用的。
给老师（本项目维护者） 本站是教程站，不是课堂投屏底本：案例和机制讲解忠实于备课材料， 但学习通题号、计分口径、时间账等课堂要素不在本站呈现（那部分以《05_正式教案》《逐字稿》为准）。 批量转化请严格按 CONVERSION-SPEC.md 执行。

学情统计怎么看：每页右下角橙色「学情」按钮是学生的学习档案 （到课、停留时长、演示次数、自测自评、问 AI 助教的记录）。数据先存在学生本机， 一键导出 JSON 当作业交；把全班文件拖进 tools/teacher-dashboard.html， 即可在你自己电脑上汇总出班级学情（不需要服务器、断网可用、数据不外传）。

AI 助教使用说明

每个页面右下角都有一个蓝色「AI」浮窗，是本课程的 AI 助教。它有两种用法，默认就能用，不依赖任何账号。

模式一 · 离线导览（默认，无需任何 Key） 打开任意课时页，点右下角「AI」即可提问。没填 Key 时，它会用关键词匹配帮你定位到相关章节，并给出直达链接——断网也能用。适合问「这个概念在第几课哪一节」「我想跳去某处复习」这类问题。
模式二 · 联网解答（填你自己的 Key） 点浮窗里的 ⚙ 设置，选服务商（DeepSeek / 通义千问 / 自定义 OpenAI 兼容），粘贴你自己的 API Key。保存后，助教会基于当前课时正文回答你的问题；卡在实操时，把那一步或报错贴给它，它会帮你定位步骤、给排查思路。
  • Key 只存你本机浏览器（localStorage），对话只发往你选的服务商，不经任何中间服务器。
  • 没填 Key 时完全不发任何网络请求；填了 Key 的对话也只连你选的官方接口。
  • AI 可能出错——以课程资料和老师为准。它是辅助自学工具，不是标准答案来源。
提示 个别服务商不允许浏览器直接跨域调用（CORS）。若联网解答报错，用本机预览服务（python tools/serve.py）打开本站，或先用离线导览模式。
